# 🛸 Drone Terminal Quest

Интерактивный веб-симулятор и обучающая консольная игра, в которой игрок управляет дроном с помощью команд на JavaScript через встроенный терминал.

## 🎯 О проекте

**Drone Terminal Quest** — это прототип образовательной платформы для изучения основ программирования, работы с алгоритмами и консольным интерфейсом. Игрок выполняет миссии, навигация и взаимодействие с миром происходят через написание кода.

### 🌟 Ключевые фичи:
* **Интерактивный CLI-терминал:** поддержка базовых системных команд (`ls`, `cat`, `whoami`, `scan`, `theme`).
* **Игровой движок:** управление объектами через JS API (`drone.move()`, `drone.grab()`).
* **Кастомизация UI:** поддержка смены цветовых тем консоли (`green`, `pink`, `cyan`).
* **Система миссий:** пошаговые задания с проверкой координат и условий выполнения.

---

## 🛠️ Технологии

* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **Консольный парсер:** Custom JS Interpreter / Command Line Interface
* **Деплой:** Vercel / GitHub Pages
